FREDY AGUILAR — DIGITAL PORTFOLIO
=================================

PARA PROBAR
1. Extrae la carpeta si descargaste el ZIP.
2. Abre index.html con tu navegador, o abre la carpeta en VS Code.
3. Para editar el diseño, modifica style.css.
4. Para editar contenido, modifica index.html.
5. Para interacciones, modifica script.js.

ANTES DE PUBLICAR — PERSONALIZA
- Cambia fredy.aguilar@example.com por tu correo real.
- Cambia los links genéricos de GitHub y LinkedIn por tus perfiles.
- Añade tu foto profesional: puedes reemplazar el bloque "Tu fotografía profesional".
- Coloca tu CV PDF en una carpeta assets con el nombre Fredy_Aguilar_CV.pdf.
- Confirma tecnologías, estado y detalles de cada proyecto; la descripción es editable.
- Añade enlaces de demo/repositorios que estén publicados y funcionen.

PUBLICACIÓN GRATUITA
Puedes publicar esta página con GitHub Pages. Mantén index.html, style.css y script.js
en la raíz del repositorio.
